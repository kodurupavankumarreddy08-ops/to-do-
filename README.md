# 🚀 Task Master: Premium Next.js To-Do Template

[![Next.js](https://img.shields.io/badge/Next.js-15-black?style=for-the-badge&logo=next.js)](https://nextjs.org/)
[![TypeScript](https://img.shields.io/badge/TypeScript-5-blue?style=for-the-badge&logo=typescript)](https://www.typescriptlang.org/)
[![Vanilla CSS](https://img.shields.io/badge/Vanilla_CSS-3-orange?style=for-the-badge&logo=css3)](https://developer.mozilla.org/en-US/docs/Web/CSS)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg?style=for-the-badge)](https://opensource.org/licenses/MIT)

**Task Master** is a high-performance, aesthetically pleasing To-Do List project template designed for open-source developers who value clean code and premium UI. Built with the latest **Next.js 15 (App Router)**, **TypeScript**, and **Vanilla CSS**.

---

## ✨ Features

-   **💎 Premium Dark Mode**: A sleek, obsidian-themed interface with glassmorphic accents and high-contrast typography.
-   **⚡ High Performance**: Zero external UI libraries or heavy CSS frameworks. Just pure, optimized Vanilla CSS.
-   **🔄 Persistent State**: Integrated `localStorage` support ensures your tasks are preserved across sessions.
-   **🎯 Interactive UX**: Smooth micro-animations for adding, completing, and deleting tasks.
-   **📱 Fully Responsive**: Optimized for all screen sizes, from mobile phones to high-resolution desktops.
-   **🔍 Smart Filtering**: Instantly switch between *All*, *Active*, and *Completed* tasks.

---

## 🛠️ Tech Stack

-   **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
-   **Language**: [TypeScript](https://www.typescriptlang.org/)
-   **Styling**: Pure CSS3 (Global Design System)
-   **State**: React Hooks (`useState`, `useEffect`)
-   **Linting**: ESLint (Next.js config)

## 🚀 Quick Start

Follow these steps to get your own instance of Task Master running locally:

### 1. Prerequisites
Ensure you have **Node.js 18.17.0** or later installed.

### 2. Installation
Clone the repository and install dependencies:
```bash
git clone https://github.com/your-username/task-master.git
cd task-master
npm install
```

### 3. Start Development
Launch the development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser to see the results.

### 4. Production Build
To create an optimized production build:
```bash
npm run build
npm start
```
